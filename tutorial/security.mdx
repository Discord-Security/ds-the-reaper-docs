É normal que o seu servidor use bots de segurança como o Security. O problema é que o Security costuma entrar em conflito com o The Reaper: ele checa quantos banimentos um usuário faz em pouco tempo, e o uso de vários banimentos acaba prejudicando o bom funcionamento do The Reaper no seu servidor.

<Frame>
  <img
    src="https://i.imgur.com/7ip8xEr.png"
    alt="Exemplo do conflito entre o Security e o The Reaper"
  />
</Frame>

Relaxe, nem tudo está perdido e você não precisa tirar o Security para resolver isso. A solução é simples: coloque o The Reaper na whitelist do Security.

## Como resolver

<Steps>
  <Step title="Use o comando de whitelist do Security">
    No seu servidor, envie este comando:

    ```text
    /whitelist add_user user:992615467715940392 category:Users: All
    ```
  </Step>
  <Step title="Confira o resultado">
    O Security confirma que o The Reaper foi adicionado à whitelist.

    <Frame>
      <img
        src="https://i.imgur.com/E2YrNZT.png"
        alt="Confirmação do Security após adicionar o The Reaper à whitelist"
      />
    </Frame>
  </Step>
</Steps>
