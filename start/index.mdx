## O que você quer fazer?

| Seu objetivo | Comece aqui |
| --- | --- |
| Impedir a entrada de contas muito recentes | [Antifake](/commands/antifake) |
| Controlar mensagens repetidas | [Antispam](/commands/antispam) e [Antiflood](/commands/antiflood) |
| Banir ou advertir um membro | [Ban](/commands/ban) e [Warn](/commands/warn) |
| Preparar mensagens de boas-vindas | [Welcome](/commands/welcome) |
| Salvar uma cópia de segurança | [Backup](/commands/backup) |
| Entender banimentos entre servidores | [Rede e gravidades](/owners/gravidades) |

<Info>
  Os exemplos desta documentação usam a interface de comandos com barra do Discord, começando por `/`. Em cada página você encontra o objetivo, os campos e os cuidados importantes.
</Info>
