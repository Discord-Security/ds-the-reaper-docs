O comando **/bans** permite consultar banimentos. Use para procurar banimentos, consultar detalhes e exportar a lista.

<Info>
  **Permissão para executar:** Administrador (referência inicial; a exigência específica poderá ser ajustada).
</Info>

## Passo a passo

<Steps>
  <Step title="Encontre o comando">
    Digite `/bans` no Discord e selecione o comando do The Reaper.
  </Step>
  <Step title="Preencha as opções">
    Escolha os campos apresentados no Discord, conforme as funções descritas abaixo.
  </Step>
  <Step title="Confirme e confira">
    Envie o comando e confira a resposta do bot.
  </Step>
</Steps>

## Parâmetros

| Campo | Significado |
| --- | --- |
| `ID` | Identifique o ID do usuário banido. |
| `Motivo` | Coloque como parâmetro de busca o motivo dado. |

<Warning>
  Confira o ID ou o motivo antes de pesquisar.
</Warning>

## Opções do comando

O mesmo irá ter 3 grupos:

<Tabs>
  <Tab title="Info">
    Informações de um banimento, informando assim o usuário, id e motivo.

    - `ID`: Identifique o ID do usuário banido.
  </Tab>
  <Tab title="Pesquisar">
    Informações de vários banimentos, dizendo ID, tag e motivo destacando a palavra-chave.

    - `Motivo`: Coloque como parâmetro de busca o motivo dado.
  </Tab>
  <Tab title="Exportar">
    Exporte uma lista em txt com todos os banimentos do seu servidor.
  </Tab>
</Tabs>
