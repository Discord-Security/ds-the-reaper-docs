O comando **/bans** mostra o máximo de detalhes sobre os banimentos do seu servidor. Você pode consultar um banimento específico, pesquisar por motivo ou exportar a lista inteira.

<Info>
  **Permissão necessária:** Administrador.
</Info>

## Como usar

Digite **/bans** no chat e escolha uma das três opções abaixo.

<Tabs>
  <Tab title="Info">
    Mostra as informações de um banimento: o usuário, o ID e o motivo.

    | Campo | O que colocar |
    | --- | --- |
    | `ID` | O ID do usuário banido. |

    <Frame caption="Opção Info do comando /bans no Discord.">
      <img
        src="https://i.imgur.com/nERFoI9.png"
        alt="Opção Info do comando /bans mostrando os detalhes de um banimento"
      />
    </Frame>
  </Tab>
  <Tab title="Pesquisar">
    Mostra vários banimentos de uma vez, com ID, tag e motivo, destacando a palavra-chave que você pesquisou.

    | Campo | O que colocar |
    | --- | --- |
    | `Motivo` | O motivo que você quer usar como busca. |

    <Frame caption="Opção Pesquisar do comando /bans no Discord.">
      <img
        src="https://i.imgur.com/dCWbZU4.png"
        alt="Opção Pesquisar do comando /bans listando banimentos por motivo"
      />
    </Frame>
  </Tab>
  <Tab title="Exportar">
    Exporta uma lista em arquivo txt com todos os banimentos do seu servidor.

    <Frame caption="Opção Exportar do comando /bans no Discord.">
      <img
        src="https://i.imgur.com/XxSmAa2.png"
        alt="Opção Exportar do comando /bans gerando a lista de banimentos"
      />
    </Frame>
  </Tab>
</Tabs>

<Tip>
  Não sabe como copiar o ID de um usuário? Siga o guia [Como pegar IDs no Discord](/tutorial/devsettings).
</Tip>
