O comando **/mute** do The Reaper permite silenciar temporariamente um membro. Use quando é necessário impedir temporariamente que um membro envie mensagens.

<Info>
  **Permissão para quem executa:** Administrador, como referência inicial desta documentação. Algumas funções podem aceitar permissões mais restritas.
</Info>

## Como usar no Discord

<Steps>
  <Step title="Abra o comando">
    Em um canal do servidor, digite `/mute` e selecione a opção do **The Reaper** no menu de comandos do Discord.
  </Step>
  <Step title="Preencha os campos">
    O Discord apresenta os campos necessários. Confira os nomes e as orientações abaixo antes de confirmar.
  </Step>
  <Step title="Confira e execute">
    Verifique os valores escolhidos e envie o comando. Observe a resposta do bot no Discord.
  </Step>
</Steps>

## Campos do comando

| Campo | Para que serve |
| --- | --- |
| `Usuário` | Este basta o mencioná-lo no servidor ou usar o ID de usuário. |
| `Tempo` | Diga a duração do silenciamento. |
| `Motivo` | Diga o motivo pelo silenciamento do usuário. |

<Warning>
  Defina a duração antes de confirmar a ação.
</Warning>

## Opções e exemplos da documentação original

- `Usuário`: Este basta o mencioná-lo no servidor ou usar o ID de usuário.
- `Tempo`: Diga a duração do silenciamento.

<Tip>
  Por exemplo: `1h` para 1 hora, `1d` para 1 dia, `1m` para 1 minuto.
</Tip>

- `Motivo`: Diga o motivo pelo silenciamento do usuário.

<Note>
  Este campo é opcional.
</Note>
