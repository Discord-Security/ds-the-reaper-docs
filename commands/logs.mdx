Com **/logs**, você pode registrar eventos do servidor. Use para acompanhar eventos como mensagens editadas ou excluídas.

<Info>
  **Permissão para executar:** Administrador (referência inicial; a exigência específica poderá ser ajustada).
</Info>

## Como usar

<Steps>
  <Step title="Abra o comando no Discord">
    Digite `/logs` no campo de mensagens e selecione o comando do The Reaper.
  </Step>
  <Step title="Escolha as opções">
    Preencha os campos mostrados no Discord. Os nomes e as funções disponíveis estão explicados abaixo.
  </Step>
  <Step title="Confirme a configuração">
    Revise suas escolhas, envie o comando e confira a resposta do bot.
  </Step>
</Steps>

## Parâmetros principais

| Campo | Significado |
| --- | --- |
| `Tipo` | Este basta escolher alguma das opções que o bot indicará. |
| `Canal` | Diga um dos canais do seu servidor para o bot enviar os registros. |
| `Ativado` | Defina como ativado ou não. |

<Warning>
  Escolha o tipo de registro, o canal e se o recurso estará ativado.
</Warning>

## Funções disponíveis

- `Tipo`: Este basta escolher alguma das opções que o bot indicará.
- `Canal`: Diga um dos canais do seu servidor para o bot enviar os registros.
- `Ativado`: Defina como ativado ou não.
