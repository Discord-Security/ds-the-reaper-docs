O comando **/logs** permite registrar eventos do servidor. Use para acompanhar eventos como mensagens editadas ou excluídas.

<Info>
  **Permissão necessária:** Administrador.
</Info>

## Parâmetros principais

| Campo | Significado |
| --- | --- |
| `Tipo` | Este basta escolher alguma das opções que o bot indicará. |
| `Canal` | Diga um dos canais do seu servidor para o bot enviar os registros. |
| `Ativado` | Defina como ativado ou não. |

<Warning>
  Escolha o tipo de registro, o canal e se o recurso estará ativado.
</Warning>

Digite `/logs` no Discord, preencha os parâmetros correspondentes e confirme a operação.
