O comando **/unban** do The Reaper permite remover um banimento. Use quando uma punição deve ser desfeita.

<Info>
  **Permissão necessária:** Administrador.
</Info>

## Parâmetros

| Campo | Para que serve |
| --- | --- |
| `Usuário` | Este basta o mencioná-lo no servidor ou usar o ID de usuário. |
| `Gravidade` | Deverá ser escolhida de 1 a 2 dependendo do que o usuário fez. |

<Warning>
  A gravidade escolhida define o alcance do desbanimento, conforme as regras da rede.
</Warning>

Para usar, digite `/unban` no Discord, preencha os campos indicados e confirme a ação.
