O comando **/unmute** do The Reaper permite remover um silenciamento. Use quando um membro pode voltar a participar antes do fim do castigo.

<Info>
  **Permissão necessária:** Administrador.
</Info>

## Parâmetros

| Campo | Para que serve |
| --- | --- |
| `Usuário` | Este basta o mencioná-lo no servidor ou usar o ID de usuário. |

<Warning>
  Selecione a pessoa silenciada para retirar o castigo.
</Warning>

Para usar, digite `/unmute` no Discord, preencha os campos indicados e confirme a ação.
