Com **/delete_channels**, você pode excluir canais de uma categoria. Use somente quando precisar remover os canais de uma categoria.

<Info>
  **Permissão necessária:** Administrador.
</Info>

## Parâmetros principais

| Campo | Significado |
| --- | --- |
| `Categoria` | Este solicitará somente categorias, já filtrando as opções possíveis só para categorias. |

<Warning>
  A exclusão de canais é uma ação destrutiva. Confira a seleção antes de confirmar.
</Warning>

Para usar, digite `/delete_channels` no Discord, preencha os campos indicados e confirme a ação.
