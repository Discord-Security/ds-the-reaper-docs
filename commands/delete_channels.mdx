Com **/delete_channels**, você pode excluir canais de uma categoria. Use somente quando precisar remover os canais de uma categoria.

<Info>
  **Permissão para executar:** Administrador (referência inicial; a exigência específica poderá ser ajustada).
</Info>

## Como usar

<Steps>
  <Step title="Abra o comando no Discord">
    Digite `/delete_channels` no campo de mensagens e selecione o comando do The Reaper.
  </Step>
  <Step title="Escolha as opções">
    Preencha os campos mostrados no Discord. Os nomes e as funções disponíveis estão explicados abaixo.
  </Step>
  <Step title="Confirme a configuração">
    Revise suas escolhas, envie o comando e confira a resposta do bot.
  </Step>
</Steps>

## Parâmetros principais

| Campo | Significado |
| --- | --- |
| `Categoria` | Este solicitará somente categorias, já filtrando as opções possíveis só para categorias. |

<Warning>
  A exclusão de canais é uma ação destrutiva. Confira a seleção antes de confirmar.
</Warning>

## Funções disponíveis

O mesmo irá solicitar 1 parâmetro:

- `Categoria`: Este solicitará somente categorias, já filtrando as opções possíveis só para categorias.
