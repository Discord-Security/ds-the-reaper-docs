O comando **/serverinfo** permite confira os dados de um servidor usando o nome ou ID.

<Info>
  **Permissão necessária:** Administrador.
</Info>

## Parâmetros

- `ID`: Identifique o ID do servidor ou o nome completo dele.

Digite `/serverinfo` no Discord, preencha os parâmetros correspondentes e confirme a operação.
