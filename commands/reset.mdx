O comando **/reset** permite apagar os dados de configuração. Use apenas quando quiser remover os dados do seu servidor guardados pelo The Reaper.

<Info>
  **Permissão necessária:** Administrador.
</Info>

Apaga os dados do servidor armazenados pelo The Reaper.

<Warning>
  Esta ação remove dados do servidor na base de dados do bot.
</Warning>

Digite `/reset` no Discord para executar a operação.
