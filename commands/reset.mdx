O comando **/reset** retira do banco de dados do The Reaper todos os dados do seu servidor. Use quando quiser que o bot esqueça o que guardou sobre a sua comunidade.

<Info>
  **Permissão necessária:** Administrador.
</Info>

## Como usar

Digite **/reset** no chat e escolha o comando na lista do Discord. Ele não tem campos para preencher.

<Warning>
  O comando apaga todos os dados do seu servidor no banco de dados do The Reaper. Para saber exatamente o que é guardado, veja [O que o The Reaper guarda sobre o seu servidor](/owners/dados).
</Warning>
