O comando **/revert-raid** permite reverter alterações de uma raid. Use depois de um ataque para recuperar elementos afetados no servidor.

<Info>
  **Permissão necessária:** Administrador.
</Info>

O comando procura reverter alterações dos últimos 24 horas, incluindo banimentos, canais, categorias e cargos, devolvendo cargos aos membros que ainda estão no servidor.

<Warning>
  O comando documentado no Discord é /revert-raid. Revise os efeitos antes de executar.
</Warning>

Digite `/revert-raid` no Discord para executar a operação.
