Com **/antifake**, você pode proteger contra contas recentes. Use para reduzir a entrada de contas criadas há pouco tempo.

<Info>
  **Permissão para executar:** Administrador (referência inicial; a exigência específica poderá ser ajustada).
</Info>

## Como usar

<Steps>
  <Step title="Abra o comando no Discord">
    Digite `/antifake` no campo de mensagens e selecione o comando do The Reaper.
  </Step>
  <Step title="Escolha as opções">
    Preencha os campos mostrados no Discord. Os nomes e as funções disponíveis estão explicados abaixo.
  </Step>
  <Step title="Confirme a configuração">
    Revise suas escolhas, envie o comando e confira a resposta do bot.
  </Step>
</Steps>

## Parâmetros principais

| Campo | Significado |
| --- | --- |
| `Ação` | Alterne entre banir usuários ou expulsar eles através do antifake. |
| `Tempo` | Defina um intervalo de tempo limite como, por exemplo, 3h para 3 horas. |
| `Canal` | Identifique um canal para seu relatório ser enviado. |

<Warning>
  Configure o limite de idade da conta, a punição e o canal de relatórios antes de ativar.
</Warning>

## Funções disponíveis

O mesmo irá ter 4 grupos:

<Tabs>
  <Tab title="Punição">
    Use essa opção para alternar entre punir usuários com este sistema com banimentos ou expulsões

    - `Ação`: Alterne entre banir usuários ou expulsar eles através do antifake.

    ![](https://i.imgur.com/ya0z4pl.png)
  </Tab>
  <Tab title="Tempo">
    Defina um limite de tempo (por exemplo, 1d, 1h) após a criação da conta para negar a permissão de entrada no seu servidor.

    - `Tempo`: Defina um intervalo de tempo limite como, por exemplo, 3h para 3 horas.

    ![](https://i.imgur.com/EMfXe0U.png)
  </Tab>
  <Tab title="Canal">
    Mencione um canal para que o The Reaper envie os relatórios de quem foi punido com esse sistema.

    - `Canal`: Identifique um canal para seu relatório ser enviado.

    ![](https://i.imgur.com/5yitCbs.png)
  </Tab>
  <Tab title="Ativar">
    Use essa opção para alternar entre o sistema online ou offline no seu servidor.

    ![](https://i.imgur.com/zVJQ9MC.png)
  </Tab>
</Tabs>

## Exemplo visual de configuração

Este exemplo permite percorrer a configuração do Antifake na ordem recomendada. Os campos ilustrados correspondem aos grupos descritos acima.

<DiscordAntifakeDemo />

export const DiscordAntifakeDemo = () => {
  const [step, setStep] = useState(0);
  const stages = [
    {label:"Tempo",cmd:"/antifake · opção Tempo",help:"Defina o limite de idade de conta. O exemplo 3h corresponde a três horas."},
    {label:"Punição",cmd:"/antifake · opção Punição",help:"Escolha se as contas que violarem o limite serão expulsas ou banidas."},
    {label:"Canal",cmd:"/antifake · opção Canal",help:"Selecione o canal do servidor que receberá os relatórios."},
    {label:"Ativar",cmd:"/antifake · opção Ativar",help:"Por fim, ative o sistema para começar a aplicar a configuração."}
  ];
  return <div className="not-prose rounded-xl border border-[#42454e] overflow-hidden my-5" style={{background:"#313338",color:"#f2f3f5"}}>
    <div style={{padding:"12px 16px",background:"#2b2d31",fontSize:13,fontWeight:650}}>Configuração ilustrativa no Discord</div>
    <div style={{padding:16}}>
      <div style={{display:"flex",gap:6,marginBottom:14,flexWrap:"wrap"}}>{stages.map((x,i)=><button type="button" key={x.label} onClick={()=>setStep(i)} style={{background:i===step?"#5865f2":"#4e5058",padding:"7px 10px",borderRadius:6,fontSize:12}}>{i+1}. {x.label}</button>)}</div>
      <div style={{background:"#383a40",borderRadius:8,padding:14,fontSize:14}}>{stages[step].cmd}</div>
      <p style={{color:"#b5bac1",fontSize:13,marginTop:12}}>{stages[step].help}</p>
      <button type="button" onClick={()=>setStep((step+1)%stages.length)} style={{background:"#5865f2",borderRadius:6,padding:"8px 12px",marginTop:12}}>{step===3?"Recomeçar":"Próximo passo"}</button>
    </div>
  </div>;
};
