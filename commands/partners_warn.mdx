O comando **/parcerias_aviso** envia uma mensagem de agradecimento assim que você finaliza uma parceria. Basta ativar o sistema, definir um canal e escrever a mensagem de agradecimento, que é totalmente personalizável.

<Info>
  **Permissão necessária:** Administrador.
</Info>

## Como usar

Digite **/parcerias_aviso** no chat e escolha uma das cinco opções abaixo.

<Tabs>
  <Tab title="Mensagem">
    Envia o conteúdo da sua mensagem em formato JSON. Monte tudo do seu jeito no [editor do message.style](https://message.style/app/editor), usando as [variáveis de parcerias](/owners/partners) disponíveis, e depois cole o resultado no comando. Assim a mensagem é construída de forma eficiente.

    <Frame caption="Opção Mensagem do comando /parcerias_aviso no Discord.">
      <img
        src="https://i.imgur.com/9ljPqdy.png"
        alt="Opção Mensagem do comando /parcerias_aviso no Discord"
      />
    </Frame>
  </Tab>
  <Tab title="Canal">
    Informa o canal onde você publica as parcerias.

    | Campo | O que colocar |
    | --- | --- |
    | `Canal` | Mencione o canal onde você deseja publicar parcerias. |

    <Frame caption="Opção Canal do comando /parcerias_aviso no Discord.">
      <img
        src="https://i.imgur.com/Teo0Cw7.png"
        alt="Opção Canal do comando /parcerias_aviso no Discord"
      />
    </Frame>
  </Tab>
  <Tab title="Ativar">
    Ativa o sistema para começar a notificar.

    <Frame caption="Opção Ativar do comando /parcerias_aviso no Discord.">
      <img
        src="https://i.imgur.com/v8tIe5l.png"
        alt="Opção Ativar do comando /parcerias_aviso no Discord"
      />
    </Frame>
  </Tab>
  <Tab title="Informação">
    Exibe informações úteis sobre como o sistema funciona.

    <Frame caption="Opção Informação do comando /parcerias_aviso no Discord.">
      <img
        src="https://i.imgur.com/oeRaNJB.png"
        alt="Opção Informação do comando /parcerias_aviso no Discord"
      />
    </Frame>
  </Tab>
  <Tab title="Classificação">
    Mostra um ranking de todos os staffs de parceria, informando quantas parcerias cada um fez no total.

    <Frame caption="Opção Classificação do comando /parcerias_aviso no Discord.">
      <img
        src="https://i.imgur.com/nEkOmjm.png"
        alt="Opção Classificação do comando /parcerias_aviso mostrando o ranking de staffs"
      />
    </Frame>
  </Tab>
</Tabs>
