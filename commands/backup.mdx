Com **/backup**, você pode criar e restaurar backups. Use para gerar uma cópia de segurança e recuperar a configuração do servidor.

<Info>
  **Permissão para executar:** Administrador (referência inicial; a exigência específica poderá ser ajustada).
</Info>

## Como usar

<Steps>
  <Step title="Abra o comando no Discord">
    Digite `/backup` no campo de mensagens e selecione o comando do The Reaper.
  </Step>
  <Step title="Escolha as opções">
    Preencha os campos mostrados no Discord. Os nomes e as funções disponíveis estão explicados abaixo.
  </Step>
  <Step title="Confirme a configuração">
    Revise suas escolhas, envie o comando e confira a resposta do bot.
  </Step>
</Steps>

## Parâmetros principais

| Campo | Significado |
| --- | --- |
| `BackupID` | Identifique o ID do Backup gerado no **/backup criar**. |
| `Senha` | Identifique a senha de Backups do servidor onde o backup será carregado. |

<Warning>
  Carregar um backup pode destruir a estrutura atual do servidor para recriá-la. Guarde o ID e a senha em segurança.
</Warning>

## Funções disponíveis

O mesmo irá ter 4 grupos:

<Tabs>
  <Tab title="Criar">
    Crie o backup, este irá dar um ID e uma senha para você utilizá-lo quando estiver disposto a tomar tal medida.

    ![](https://i.imgur.com/RzDVB8P.png)
  </Tab>
  <Tab title="Automático">
    Cria o backup, este irá dar um ID e uma senha para você utilizá-lo quando estiver disposto a tomar tal medida. E nas segundas-feiras às 18 horas passará uma nova cópia de segurança na sua DM.

    <Warning>
      É recomendável você abrir as suas mensagens diretas com o The Reaper para receber os backups.
    </Warning>
    ![](https://i.ibb.co/JwbksFtJ/image.png)
  </Tab>
  <Tab title="Carregar">
    Carregue com um ID e uma senha o backup criado com esse ID.

    - `BackupID`: Identifique o ID do Backup gerado no **/backup criar**.
    - `Senha`: Identifique a senha de Backups do servidor onde o backup será carregado.

    <Danger>
      **CUIDADO\!** Você ao utilizar este comando está consentindo o bot a destruir todo o seu servidor para refazer tudo o que foi guardado durante o backup.
    </Danger>
    ![](https://i.imgur.com/HozJIKs.png)
  </Tab>
  <Tab title="Remover">
    Remova do nosso banco de dados, o backup criado com esse ID.

    - `BackupID`: Identifique o ID do Backup gerado no **/backup criar**.
    - `Senha`: Identifique a senha de Backups do servidor onde o backup será apagado.

    ![](https://i.imgur.com/AqFe00W.png)
  </Tab>
</Tabs>
