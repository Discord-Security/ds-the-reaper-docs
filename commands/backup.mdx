O comando **/backup** faz uma cópia de segurança completa do seu servidor. Cada backup recebe um ID e uma senha, que você usa depois para carregar ou remover a cópia.

<Info>
  **Permissão necessária:** Administrador.
</Info>

## Como usar

Digite **/backup** no chat e escolha uma das quatro opções abaixo.

<Tabs>
  <Tab title="Criar">
    Cria o backup. O bot entrega um ID e uma senha para você usar quando estiver disposto a restaurar o servidor.

    <Frame caption="Opção Criar do comando /backup no Discord.">
      <img
        src="https://i.imgur.com/RzDVB8P.png"
        alt="Opção Criar do comando /backup mostrando o ID e a senha do backup"
      />
    </Frame>
  </Tab>
  <Tab title="Automático">
    Cria o backup, com ID e senha, e envia uma nova cópia de segurança na sua DM toda segunda-feira às 18 horas.

    <Warning>
      Abra as suas mensagens diretas com o The Reaper para conseguir receber os backups.
    </Warning>

    <Frame caption="Opção Automático do comando /backup no Discord.">
      <img
        src="https://i.ibb.co/JwbksFtJ/image.png"
        alt="Opção Automático do comando /backup no Discord"
      />
    </Frame>
  </Tab>
  <Tab title="Carregar">
    Carrega o backup criado com um determinado ID e senha.

    | Campo | O que colocar |
    | --- | --- |
    | `BackupID` | O ID do backup gerado ao usar o **/backup criar**. |
    | `Senha` | A senha de backups do servidor onde o backup será carregado. |

    <Danger>
      **Cuidado.** Ao usar este comando você autoriza o bot a destruir todo o seu servidor para refazer tudo o que foi guardado durante o backup.
    </Danger>

    <Frame caption="Opção Carregar do comando /backup no Discord.">
      <img
        src="https://i.imgur.com/HozJIKs.png"
        alt="Opção Carregar do comando /backup no Discord"
      />
    </Frame>
  </Tab>
  <Tab title="Remover">
    Remove do banco de dados do The Reaper o backup criado com esse ID.

    | Campo | O que colocar |
    | --- | --- |
    | `BackupID` | O ID do backup gerado ao usar o **/backup criar**. |
    | `Senha` | A senha de backups do servidor onde o backup será apagado. |

    <Frame caption="Opção Remover do comando /backup no Discord.">
      <img
        src="https://i.imgur.com/AqFe00W.png"
        alt="Opção Remover do comando /backup no Discord"
      />
    </Frame>
  </Tab>
</Tabs>

<Tip>
  Guarde o ID e a senha do backup em um lugar seguro. Você precisa dos dois para carregar ou remover a cópia.
</Tip>
