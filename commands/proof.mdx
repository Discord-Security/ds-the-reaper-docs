Com **/proof**, você pode enviar provas de infrações. Use para encaminhar provas de uma infração à equipe oficial do The Reaper.

<Info>
  **Permissão para executar:** Administrador (referência inicial; a exigência específica poderá ser ajustada).
</Info>

## Como usar

<Steps>
  <Step title="Abra o comando no Discord">
    Digite `/proof` no campo de mensagens e selecione o comando do The Reaper.
  </Step>
  <Step title="Escolha as opções">
    Preencha os campos mostrados no Discord. Os nomes e as funções disponíveis estão explicados abaixo.
  </Step>
  <Step title="Confirme a configuração">
    Revise suas escolhas, envie o comando e confira a resposta do bot.
  </Step>
</Steps>

## Parâmetros principais

| Campo | Significado |
| --- | --- |
| `IDs` | Indique um ou vários IDs de usuários que quebraram as suas regras. |
| `Motivo` | Diga o que esse ou esses usuários fizeram como quebra das regras do seu servidor. |
| `Imagem` | Faça o carregamento de uma imagem para isso. |

<Warning>
  Não compartilhe informações privadas desnecessárias ao enviar provas.
</Warning>

## Funções disponíveis

- `IDs`: Indique um ou vários IDs de usuários que quebraram as suas regras.
<Tip>
  Se precisares de ajuda sobre como pegar IDs de usuários, clica [aqui](/tutorial/devsettings).
</Tip>
- `Motivo`: Diga o que esse ou esses usuários fizeram como quebra das regras do seu servidor.
- `Imagem`: Faça o carregamento de uma imagem para isso.
