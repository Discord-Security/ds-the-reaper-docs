O comando **/kick** do The Reaper permite expulsar um membro. Use para retirar um membro do servidor sem aplicar um banimento.

<Info>
  **Permissão necessária:** Administrador.
</Info>

## Parâmetros

| Campo | Para que serve |
| --- | --- |
| `Usuário` | Este basta o mencioná-lo no servidor ou usar o ID de usuário. |
| `Motivo` | Diga o motivo pela expulsão do usuário. |

<Warning>
  Confirme se selecionou a pessoa correta antes de enviar o comando.
</Warning>

Para usar, digite `/kick` no Discord, preencha os campos indicados e confirme a ação.
