Com **/warn**, você pode advertir um membro. Use para avisar um membro sobre uma infração às regras.

<Info>
  **Permissão necessária:** Administrador.
</Info>

## Parâmetros principais

| Campo | Significado |
| --- | --- |
| `Usuário` | Este basta o mencioná-lo no servidor ou usar o ID de usuário. |
| `Motivo` | Diga o motivo pela advertência do usuário. |

<Warning>
  A advertência é registrada no perfil exibido pelo userinfo.
</Warning>

Para usar, digite `/warn` no Discord, preencha os campos indicados e confirme a ação.
