Com **/warn**, você pode advertir um membro. Use para avisar um membro sobre uma infração às regras.

<Info>
  **Permissão para executar:** Administrador (referência inicial; a exigência específica poderá ser ajustada).
</Info>

## Como usar

<Steps>
  <Step title="Abra o comando no Discord">
    Digite `/warn` no campo de mensagens e selecione o comando do The Reaper.
  </Step>
  <Step title="Escolha as opções">
    Preencha os campos mostrados no Discord. Os nomes e as funções disponíveis estão explicados abaixo.
  </Step>
  <Step title="Confirme a configuração">
    Revise suas escolhas, envie o comando e confira a resposta do bot.
  </Step>
</Steps>

## Parâmetros principais

| Campo | Significado |
| --- | --- |
| `Usuário` | Este basta o mencioná-lo no servidor ou usar o ID de usuário. |
| `Motivo` | Diga o motivo pela advertência do usuário. |

<Warning>
  A advertência é registrada no perfil exibido pelo userinfo.
</Warning>

## Funções disponíveis

- `Usuário`: Este basta o mencioná-lo no servidor ou usar o ID de usuário.
- `Motivo`: Diga o motivo pela advertência do usuário.
