O comando **/lockdown** fecha todos os chats do servidor para impedir que os membros digitem. Ele é útil em situações como uma raid: os membros continuam vendo os chats, mas não conseguem escrever.

<Info>
  **Permissão necessária:** Administrador.
</Info>

## Como usar

Digite **/lockdown** no chat e escolha uma das duas opções abaixo.

<Tabs>
  <Tab title="Ativar">
    Ativa o sistema e o servidor fica totalmente fechado para os membros digitarem. Eles só poderão visualizar os chats e, se você tiver informado, ver o aviso com o motivo.

    | Campo | O que colocar |
    | --- | --- |
    | `Motivo` | Envie um motivo e o bot cria uma embed em todos os canais bloqueados avisando por que o servidor está bloqueado. |
    | `Tempo` | O tempo que o servidor deve permanecer bloqueado, por exemplo `7h 45m`. |

    <Frame caption="Opção Ativar do comando /lockdown no Discord.">
      <img
        src="https://i.imgur.com/kyNiKcR.png"
        alt="Opção Ativar do comando /lockdown no Discord"
      />
    </Frame>
  </Tab>
  <Tab title="Desativar">
    Desativa o sistema depois que tudo estiver resolvido e o servidor volta a ficar como estava antes.

    <Frame caption="Opção Desativar do comando /lockdown no Discord.">
      <img
        src="https://i.imgur.com/VXntfx4.png"
        alt="Opção Desativar do comando /lockdown no Discord"
      />
    </Frame>
  </Tab>
</Tabs>

## Quando usar

Use o lockdown quando o servidor estiver sob ataque e você precisar parar tudo rapidamente. Depois, com a situação controlada, desative o sistema para devolver o servidor ao normal.
