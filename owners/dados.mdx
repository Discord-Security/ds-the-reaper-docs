O The Reaper guarda alguns dados importantes do Discord no banco de dados dele para que as funções do bot funcionem. Esta página mostra o que fica guardado e como você pode apagar esses dados quando quiser.

## O que é guardado

O The Reaper armazena dados relacionados ao seu servidor, como:

- **Comandos** usados, com seus argumentos, entradas e saídas de usuários.
- **ID** do servidor e dos canais que usam comandos que exigem dados permanentes no banco de dados.
- **Logs**, **punições** e **avisos** realizados com o The Reaper.
- **Senhas**, **websites**, **cargos** e **mensagens** necessários para algumas funcionalidades.
- A mensagem de parceria, caso o servidor permita.

<Info>
  O The Reaper não armazena nada que possa comprometer a privacidade de usuários, mensagens ou informações.
</Info>

## Como apagar os dados

<Tabs>
  <Tab title="Apagar tudo">
    Para remover todos os dados do servidor, use uma destas opções:

    - **Remova o The Reaper do servidor.** Os dados são apagados após 6 horas.
    - **Use o comando [/reset](/commands/reset).** Ele retira do banco de dados todos os dados do seu servidor.
  </Tab>
  <Tab title="Apagar em parte">
    Os dados de cada função são apagados automaticamente quando você desativa a função que os usa. Por exemplo, ao desativar um sistema que guarda dados do servidor, os dados dele deixam de ficar guardados.
  </Tab>
</Tabs>
